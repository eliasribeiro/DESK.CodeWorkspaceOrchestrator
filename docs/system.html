Guia de System Design

O Design System do Conductor é baseado em um tema escuro sofisticado (Dark Mode). Ele foca em bordas sutis, superfícies de elevação com diferentes tons de preto/cinza, tipografia clara (sans-serif para principal e monoespaçada para código/atalhos) e uso estratégico de cores para indicar status.
